# SBMS development record

This vault belongs to the Rust implementation in this repository. It records
only the current facts, accepted boundaries, and executable work.

- `Current.md` is the one current-state page.
- `Versions/` records verified release boundaries and usage.
- `Tasks/` contains bounded work with acceptance evidence.
- `Decisions/` contains choices that constrain the code.

Update pages by replacing stale statements. Do not append chat transcripts,
incident diaries, speculative release plans, or parallel versions of reality.
Git history is the archive.
