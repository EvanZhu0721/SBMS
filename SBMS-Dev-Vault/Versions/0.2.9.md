# 0.2.9

Status: implemented and exercised locally as a complete install/upgrade/uninstall
preview.

## Product capability

- Includes the 0.2.8 tray, reversible window migration, fixed 4K240 virtual
  source, mirror, and captured mouse route.
- Adds a single-instance tray and `sbms shutdown` control event so maintenance
  never needs to terminate an active mapping blindly.
- Adds one x64 Inno Setup executable.
- Registers one per-user elevated Task Scheduler logon entry because the current
  cross-session IDD transport uses `Global\` kernel objects.
- Upgrade waits for graceful session cleanup, updates installer-owned files,
  and deletes only an explicit allowlist of known legacy artifacts.
- Uninstall waits for graceful cleanup, removes verified owned logon tasks, and
  deletes every exactly matched SBMS OEM INF without `/force`. External cleanup
  failures trigger compensation before the registered application files are
  retained.

## Local evidence

- Installed 0.2.9 over a legacy `C:\Program Files\SBMS` tree and confirmed only
  the declared 0.2.9 payload remained.
- Uninstalled and confirmed: install root absent, scheduled task absent, tray
  process count zero, and SBMS Driver Store package count zero.
- Reinstalled from the same package and confirmed the `Highest` logon task was
  running and an elevated three-second virtual-device lifecycle returned zero.

## Distribution boundary

This is a locally trusted preview package, not a public production installer.
The test certificate is not publicly trusted and has no public timestamp.
Production distribution still requires trusted executable/installer signing and
the proper Microsoft driver-signing route.
