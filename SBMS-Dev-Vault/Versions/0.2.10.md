# 0.2.10

Status: input-latency and mirrored-cursor fixes implemented and exercised with
one bounded elevated mapping lifecycle.

## Product changes

- Separates Raw Input and low-level hook message pumping from the synchronous
  4K `StretchDIBits` worker.
- Coalesces queued relative movement packets and injects only the latest
  absolute virtual-desktop position per drained message batch.
- Explicitly composites a fixed high-contrast pointer marker at the current
  visible source position inside each leased BGRA frame.
- Reuses the latest published frame when only cursor state changes, so cursor
  movement does not depend on a new desktop-damage frame.

## Verification boundary

- Rust formatting and all-target compile, Clippy, and test commands pass.
- An elevated ten-second mapping lifecycle against the physical 240 Hz target
  completed with exit code zero.
- A live screenshot of the physical mirror, using its post-topology coordinates,
  shows the pointer marker at the mapped virtual-screen center.
- Final subjective latency and cursor-visibility confirmation still requires
  observation during interactive mouse movement; lifecycle success alone does
  not prove perceived input quality.
