# 1.0.0

## Product changes

- Persists the selected physical display by stable DisplayConfig ID in
  `%LOCALAPPDATA%\SBMS\config-v1.json`.
- Adds `sbms config path|show|set-target|clear-target|reset`; `sbms map` falls
  back to the saved target when `--target` is omitted.
- Preserves malformed or unsupported configuration files and requires an
  explicit reset before replacement.
- Publishes a pure Rust sizing API with explicit pixel geometry, physical
  dimensions or diagonal, rotation, physical/integer scaling strategy,
  alignment, and preferred refresh.
- Makes input forwarding consume the same `CoordinateTransform` used by future
  rendering geometry.
- Keeps IddCx's default software cursor as the only pointer path. SBMS does not
  draw a duplicate cursor.

## Boundary

- The sizing API calculates a planned virtual mode but does not yet change the
  driver's fixed 3840x2160@240 mode.
- UI does not read or write configuration in this release.
- Touch, pen, absolute pointer, and runtime topology recovery remain absent.
