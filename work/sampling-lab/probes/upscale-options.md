# 放大色度重建候选

推荐：保留原去彩边预处理，用 EWA 重建亮度，用同一份预处理输入的双线性值重建色度。仅用于放大，不改 1:1 与缩小分支。

```text
E = existing EWA(cleanSource)
B = bilinear(cleanSource)
Y(c) = dot(c, [0.2126, 0.7152, 0.0722])
result = clamp(vec3(Y(E)) + B - vec3(Y(B)), 0, 1)
```

在裁切前保留 EWA 的亮度；裁切到显示色域时，饱和色边缘亮度仍可能稍变。不要称作亮度逐像素完全不变。双线性色度是同分辨率纹理的四点凸组合，没有引入 4:2:0、没有减少纹理分辨率。输出量化可能使色差极值与双线性参考相差 1/255。

## 对照

`node work/sampling-lab/probes/upscale-options.cjs` 复现 [数值](upscale-options.json) 和 [对照图](upscale-options.png)。脚本使用 `sampleAt('hq')` 作为旧 EWA，不使用新 `hq-stable`。原始真实 GDI 截图独立生成，未重新缩放字体。统计包含六行英文、中文、代码、浅底和深底。每个源字体均测 2×、1.5×；共 8 组 ClearType、8 组灰度、6 组真实图标、2 组彩线。

2× 源字体结果，数字为相对 SBMS 的色度总量变化；负数代表减少：

| 源字高 | 旧 EWA | 推荐双线性色度 | 正权 EWA 色度 | 色度幅度上限 |
|---|---:|---:|---:|---:|
| 6 px | +28.4% | −15.8% | −19.6% | −17.6% |
| 8 px | +15.4% | −24.2% | −27.3% | −26.3% |
| 12 px | −31.8% | −51.5% | −55.2% | −54.0% |
| 15 px | −54.2% | −67.0% | −69.7% | −68.9% |

这里的“正权 EWA”明确指把现有 EWA 核所有负权置零后归一化，包括外部正旁瓣；不是对所有正权重采样核的结论。“幅度上限”指保留旧 EWA 色度方向，将幅度限制为双线性色度的 `max-min`。

1.5× 的 8 px PNG 为奇数宽，输出尺寸取整后横向倍率约 1.50134；所有候选使用同一中心坐标。完整倍率记录在 JSON 的 `actualScale`，此行不是整幅 2560→3840 场景的精确替身。

## 真实颜色的代价

三个真实 PNG 先经 Pillow Lanczos 统一缩至 48 px，再合成同一深底输入，所有候选共享该输入。这和浏览器自身缩图的像素不保证相同，不用这里的绝对数值替代主线程 GPU 报告。

2× 下，相比旧 EWA 的全图 RGB 平均绝对差（0–255；含背景，差异大小不是画质分数）：

| 图标 | 推荐双线性色度 | 正权 EWA 色度 |
|---|---:|---:|
| TikTok | 0.556 | 0.865 |
| Firefox | 0.925 | 1.560 |
| VS Code | 0.631 | 1.155 |

推荐方案仍会让真实彩色轮廓比旧 EWA 稍柔；图标并非逐像素保持原样。相比正权候选，变化更局限于邻近边缘，目视保留 TikTok 的青红轮廓、Firefox 的渐变和 VS Code 的内外边界。

1 px 真红线在 2× 时的中间横截面色度：

- SBMS 与推荐方案均为 `[64,191,191,64]`，只有四个非零像素。
- 幅度上限方案变为 `[49,191,191,49]`，真实线条侧缘也被额外降低。
- 正权方案为十二个非零像素，主峰 179，远处还有 12/8 的尾部；外部正旁瓣导致更宽的色度扩散。
- 旧 EWA 有十二个非零像素，主峰 247。锐利的中心和外围色度振铃同时被强化。

因此选择双线性色度，不以“文字色度降得最多”为目标。它不试图判断哪些像素是文字，而是避免重建核对色度的额外锐化与振铃。八组灰度对照均与旧 EWA 逐字节一致；真实彩色图标的亮度 MAE 约 0.07–0.10/255，来自裁切和量化，不能声称所有彩色像素亮度不变。

## 边界

本次只做候选筛选和 CPU 像素计算，不是 GPU 性能基准、生产 SBMS 测试、视频编码后测试或视觉质量总分。主线程另行验证 GPU 一致性和动态展示。输入缺失的笔画无法重建；灰度上的既有 EWA 振铃也不由本次色度改动修复。

对照图已按原始尺寸目视核验：三行文字节选、三个完整真实图标和完整细线均可见。图中 2× 采样结果额外用最近邻放大 2× 以便检查，不改变参与统计的像素。
